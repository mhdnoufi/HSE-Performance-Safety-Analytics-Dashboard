HSE Performance & Safety Analytics Dashboard | Power BI Project

Developed an interactive Power BI dashboard to analyze workplace HSE performance, including incidents, near misses, unsafe observations, hazards, corrective actions, and safety trends.

The project focuses on identifying high-risk areas, recurring safety issues, and corrective-action gaps to support data-driven decision-making and proactive safety management.

Tools: Power BI | Power Query | DAX | Excel

Focus: HSE Analytics | Safety KPIs | Incident Analysis | Risk Monitoring | Corrective Actions
